键盘核心区的粉色与棕色区域承载 CapsLock Enhancement 最高频的操作。导航与删除
两个类目合计占据 282 条映射中的 114 条 —— 这也是整套布局里最值得先学的部分。

> [!IMPORTANT]
> 若无特别说明，本页所有组合都假定 {{< kbd "✱" >}} Hyper 已经按下。
> 表中的「+ {{< kbd "⌘" >}}」即表示 {{< kbd "✱" "⌘" >}} 再加上对应按键。

## 导航键组 {#navigation}

{{< kbd "H" >}} {{< kbd "J" >}} {{< kbd "K" >}} {{< kbd "L" >}}
分别向左、下、上、右移动，与 Vim 完全一致；正上方的
{{< kbd "U" >}} {{< kbd "I" >}} {{< kbd "O" >}} {{< kbd "P" >}} 把同样的思路
扩展到整页与整行：Page Up、Home、End、Page Down。

这八个键是全键盘上唯一在九个平面上都有映射的按键。下面每一组平面负责一件事，
合起来占据 V3.1 中 282 条映射里的 72 条。

### 移动与选择文本 {#selection}

文本层的规律只有一条：按住 {{< kbd "⌘" >}}，移动就变成选择 —— 因为规则发出的
是同一个方向键再加上 {{< kbd "⇧" >}}。再叠加 {{< kbd "⌥" >}}，选择单位随之
扩大：一个字符变成一个词，一行变成三行，半行变成整行。

| 按键 | Hyper | + {{< kbd "⌘" >}} | + {{< kbd "⌘" "⌥" >}} |
| :--: | :-- | :-- | :-- |
| {{< kbd "H" >}} | 左移 | 向左选择 | 向左选词 |
| {{< kbd "J" >}} | 下移 | 向下选行 | 向下选择三行 |
| {{< kbd "K" >}} | 上移 | 向上选行 | 向上选择三行 |
| {{< kbd "L" >}} | 右移 | 向右选择 | 向右选词 |
| {{< kbd "U" >}} | 上一页 | 选择上一页 | 选择上一页 |
| {{< kbd "I" >}} | 行首 | 选择至行首 | 从行尾选至行首 |
| {{< kbd "O" >}} | 行尾 | 选择至行尾 | 从行首选至行尾 |
| {{< kbd "P" >}} | 下一页 | 选择下一页 | 选择下一页 |
{caption="0、1、3 号平面 —— 移动、选择、扩大选择"}

这也是 {{< kbd "✱" "⌘" "⌥" "I" >}} 先跳到行尾、再反向选回行首的原因：不碰鼠标
就精确选中一整行，这是最快的做法。

### 切换应用、窗口、标签页与桌面 {#switching}

{{< kbd "⇧" >}} 在**容器**之间移动 —— 你正在看的那个东西，而不是里面的文字；
{{< kbd "⌃" >}} 则是在和窗口服务器对话。

| 组合 | 实际发出 | 效果 |
| :-- | :-- | :-- |
| {{< kbd "✱" "⇧" "J" >}} / {{< kbd "✱" "⇧" "K" >}} | {{< kbd "⌘" "⇥" >}} / {{< kbd "⌘" "⇧" "⇥" >}} | 下一个 / 上一个应用 |
| {{< kbd "✱" "⇧" "H" >}} / {{< kbd "✱" "⇧" "L" >}} | {{< kbd "⌃" "⇧" "⇥" >}} / {{< kbd "⌃" "⇥" >}} | 上一个 / 下一个标签页 |
| {{< kbd "✱" "⇧" "I" >}} / {{< kbd "✱" "⇧" "O" >}} | {{< kbd "⌘" "⇧" "`" >}} / {{< kbd "⌘" "`" >}} | 同一应用的上一个 / 下一个窗口 |
| {{< kbd "✱" "⇧" "U" >}} / {{< kbd "✱" "⇧" "P" >}} | {{< kbd "⌘" "⌥" "-" >}} / {{< kbd "⌘" "⌥" "=" >}} | 缩小 / 放大 |
| {{< kbd "✱" "⌃" "H" >}} / {{< kbd "✱" "⌃" "L" >}} | {{< kbd "⌃" "←" >}} / {{< kbd "⌃" "→" >}} | 上一个 / 下一个桌面 |
| {{< kbd "✱" "⌃" "K" >}} / {{< kbd "✱" "⌃" "O" >}} | {{< kbd "⌃" "↑" >}} | 调度中心 |
| {{< kbd "✱" "⌃" "J" >}} | {{< kbd "⌃" "↓" >}} | 当前应用的全部窗口 |
| {{< kbd "✱" "⌃" "I" >}} | {{< kbd "⌘" "H" >}} | 隐藏当前应用 |
| {{< kbd "✱" "⌃" "U" >}} | {{< kbd "⌃" "⌘" "F" >}} | 切换全屏 |
| {{< kbd "✱" "⌃" "P" >}} | {{< kbd "⌘" "␣" >}} | Spotlight |
{caption="⇧ 与 ⌃ 两列实际发出的按键"}

> [!NOTE]
> 标签页切换依赖 {{< kbd "⌃" "⇥" >}}，绝大多数浏览器和编辑器支持它，少数应用
> 不支持。窗口轮换用的是 macOS 自带的
> {{< kbd "⌘" "`" >}}「将焦点移到下一个窗口」，请先在**系统设置 → 键盘 →
> 键盘快捷键**中确认它已启用。

### 从核心区控制指针与滚轮 {#home-row-mouse}

另外四个平面把同样这八个键变成鼠标，双手完全不必移动。两种模式下，
{{< kbd "⇧" >}} 都是那个「油门」。

| 按键 | + {{< kbd "⌥" >}}<br>指针 | + {{< kbd "⌥" "⇧" >}}<br>指针加速 | + {{< kbd "⌃" "⇧" >}}<br>滚轮 | + {{< kbd "⌘" "⇧" >}}<br>滚轮加速 |
| :--: | :-- | :-- | :-- | :-- |
| {{< kbd "H" >}} | 指针左移 | 指针左移 | 滚轮左 | 滚轮左 |
| {{< kbd "J" >}} | 指针下移 | 指针下移 | 滚轮下 | 滚轮下 |
| {{< kbd "K" >}} | 指针上移 | 指针上移 | 滚轮上 | 滚轮上 |
| {{< kbd "L" >}} | 指针右移 | 指针右移 | 滚轮右 | 滚轮右 |
| {{< kbd "U" >}} | 左键 | 左键 | 滚轮右 | 滚轮右 |
| {{< kbd "I" >}} | 右键 | 右键 | 滚轮上 | 滚轮上 |
| {{< kbd "O" >}} | 后退键 | 后退键 | 滚轮下 | 滚轮下 |
| {{< kbd "P" >}} | 前进键 | 前进键 | 滚轮左 | 滚轮左 |
{caption="2、10、12、9 号平面 —— 两个加速平面的速度正好是旁边平面的两倍"}

| 平面 | 指针速度 | 滚轮速度 |
| :-- | :--: | :--: |
| {{< kbd "⌥" >}} / {{< kbd "⌃" "⇧" >}} | 1600 | 64 |
| {{< kbd "⌥" "⇧" >}} / {{< kbd "⌘" "⇧" >}} | 3200 | 128 |
{caption="速度是 Karabiner 的 mouse_key 单位，不是像素"}

只有鼠标中键是例外：它不在导航键上，而在 {{< kbd "✱" "⌥" "↩" >}}。

## 方向键鼠标控制 {#arrow-mouse}

物理方向键同样可以驱动指针，很多时候比切到核心区更顺手。这里
{{< kbd "⌥" >}} 减速、{{< kbd "⌘" >}} 加速，指针与滚轮两种模式都适用。

| 组合 | 结果 | 速度 |
| :-- | :-- | :-- |
| {{< kbd "✱" >}} + 方向键 | 移动指针 | 1600 |
| {{< kbd "✱" "⌥" >}} + 方向键 | 缓慢移动 | 800 |
| {{< kbd "✱" "⌘" >}} + 方向键 | 快速移动 | 4200 |
| {{< kbd "✱" "⇧" >}} + 方向键 | 滚动滚轮 | 64 |
| {{< kbd "✱" "⇧" "⌥" >}} + 方向键 | 缓慢滚动 | 32 |
| {{< kbd "✱" "⇧" "⌘" >}} + 方向键 | 快速滚动 | 256 |
{caption="方向键簇上的三档指针速度与三档滚轮速度"}

五个鼠标按键全都落在 {{< kbd "↩" >}} 上：

| 组合 | 按键 |
| :-- | :-- |
| {{< kbd "✱" "↩" >}} | 左键单击 |
| {{< kbd "✱" "⌘" "↩" >}} | 右键单击 |
| {{< kbd "✱" "⌥" "↩" >}} | 中键单击 |
| {{< kbd "✱" "⇧" "↩" >}} | 后退 |
| {{< kbd "✱" "⌃" "↩" >}} | 前进 |

## 语义删除 {#deletion}

{{< kbd "N" >}} {{< kbd "M" >}} {{< kbd "," >}} {{< kbd "." >}} 位于导航键
正下方。左边一对**向前**删除，右边一对**向后**删除，叠加修饰键则放大删除单位。

| 按键 | Hyper | + {{< kbd "⌘" >}} | + {{< kbd "⌥" >}} |
| :--: | :-- | :-- | :-- |
| {{< kbd "N" >}} | 删除前一个词 | 删除至行首 | 删除至行首 |
| {{< kbd "M" >}} | 删除前一个字符 | 删除前一个词 | 下移当前行 |
| {{< kbd "," >}} | 删除后一个字符 | 删除后一个词 | 上移当前行 |
| {{< kbd "." >}} | 删除后一个词 | 删除至行尾 | 删除至行首 |
{caption="N 与 M 从光标向前删，逗号与句点向后删"}

有两处刻意打破了规律。{{< kbd "✱" "⌥" "N" >}} 与 {{< kbd "✱" "⌥" "." >}}
都发送 {{< kbd "⌘" "⌫" >}}，把光标到行首的内容一次清空，所以这一组的两个外侧
键就是「这行不要了」。而 {{< kbd "✱" "⌥" "M" >}} 与 {{< kbd "✱" "⌥" "," >}}
根本不删除：它们发出的是 {{< kbd "⌥" "⇧" "↓" >}} 与 {{< kbd "⌥" "⇧" "↑" >}}，
也就是 IntelliJ、VS Code 等编辑器通用的上下移动整行。

## 数字键盘鼠标 {#mousekey}

如果键盘带小键盘，Hyper 会把整块小键盘变成一只鼠标：数字键给出以
{{< kbd "5" >}} 为中心的八个方向，顶行滚动，底边与右侧是五个按键。

| 小键盘按键 | 映射 |
| :-- | :-- |
| {{< kbd "7" >}} {{< kbd "8" >}} {{< kbd "9" >}} {{< kbd "4" >}} {{< kbd "6" >}} {{< kbd "1" >}} {{< kbd "2" >}} {{< kbd "3" >}} | 八个指针方向，含四个斜向 |
| {{< kbd "5" >}} | 停止 —— 发送速度为零的指针事件 |
| {{< kbd "/" >}} {{< kbd "=" >}} | 滚轮上 / 下 |
| {{< kbd "Num Lock" >}} {{< kbd "*" >}} | 滚轮横向滚动 |
| {{< kbd "0" >}} | 左键单击 |
| {{< kbd "." >}} | 中键单击 |
| {{< kbd "⌤" >}} | 右键单击 |
| {{< kbd "+" >}} / {{< kbd "-" >}} | 前进 / 后退 |
{caption="Hyper 加小键盘：指针、滚轮与全部五个鼠标按键"}

速度修饰键与别处一致：{{< kbd "⌥" >}} 把指针降到大约一半，{{< kbd "⌘" >}}
提升一倍，再加 {{< kbd "⇧" >}} 则把指针移动换成同档速度的滚轮移动。
